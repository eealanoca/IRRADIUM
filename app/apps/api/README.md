# API de IRRADIUM

Inicia la API junto a la interfaz desde la raíz con `./irradium start`.
Documentación HTTP: http://127.0.0.1:8001/docs.

El catálogo está en `/api/irradiators`. Las rutas de trabajo son
`/irradiators/IV/api/...`. Las categorías I–III están deshabilitadas.
Los casos y resultados se guardan en `workspace/irradiators/IV/`.
Consulta el README y ARCHITECTURE.md de la raíz.
